Invoices that arrive in the billing mailbox are processed on their own. If you have a PDF invoice that didn't arrive by email, you can upload it yourself.

## Before you start

- You need to sign in to Alfred with the **Operator** role. See [Sign in to Alfred](/en/alfred/ingresar).
- The invoice has to be a **PDF** file. Alfred doesn't accept other formats for invoices.

## Upload an invoice

<Steps>
  <Step title="Open the dialog">
    On the dashboard, select **New Invoice**. The **Process Invoice** dialog opens.

    You can also drag the PDF and drop it onto the page.
  </Step>
  <Step title="Choose the file">
    Select the PDF from your computer.
  </Step>
  <Step title="Process it">
    Confirm from the **Process Invoice** dialog. Alfred starts processing the invoice.
  </Step>
  <Step title="Follow the task">
    Go back to the dashboard and find the task in **Recent tasks**. See what each status means in [Dashboard and tasks](/en/alfred/panel-y-tareas).
  </Step>
</Steps>

## If something goes wrong

- If the file isn't a PDF, Alfred shows **Only PDF files are allowed**.
- If the upload fails, Alfred shows **Upload failed**. If the file is very large, split or compress it and try again.

See what to do about each message in [Troubleshooting](/en/alfred/problemas).
