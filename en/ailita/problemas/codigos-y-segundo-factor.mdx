Ailita uses two kinds of code: the one that arrives by email and the one from your authenticator app (or a backup code). Find your case.

<Tip>
  The email code is sent on its own once you type all six digits. You don't need to select anything else.
</Tip>

## Email codes

### The code doesn't arrive

**Why:** the email can take a little while, land in another folder or have been sent to a different address.

**What to do:**

1. Check your spam or junk folder.
2. Confirm you typed your address correctly. If it's wrong, use **Use another email** and start again.
3. Wait a moment and select **Resend code**. You'll see "We sent you a new code.".
4. Always use the most recent code.

**Still stuck:** [ask for help](/en/ayuda/soporte).

### That code is wrong or has expired.

**Why:** the code or link you used is mistyped, is from an earlier send or no longer works.

**What to do:** select **Resend code** and use the latest code you receive.

**Still stuck:** [ask for help](/en/ayuda/soporte).

### Too many attempts with this code. Ask for a new one.

**Why:** you tried several times with the same code.

**What to do:** select **Resend code** and use the new code.

**Still stuck:** [ask for help](/en/ayuda/soporte).

### Wait a few seconds before asking for another code.

**Why:** you asked for another code too quickly.

**What to do:** wait a few seconds and select **Resend code** again.

**Still stuck:** [ask for help](/en/ayuda/soporte).

### We already sent you a new code.

**Why:** no more resends are available for this sign-in.

**What to do:** check your email, including the spam folder. If you can't find it, start the sign-in again from the beginning.

**Still stuck:** [ask for help](/en/ayuda/soporte).

## Authenticator app and backup codes

### That code is wrong.

**Why:** the code from your authenticator app or the backup code doesn't match.

**What to do:**

1. Check that your phone's clock is set to automatic.
2. Open your authenticator app and make sure you're looking at the right account.
3. Type the current code. App codes change every short while.
4. If the app doesn't work for you, use an 8-character backup code.

**Still stuck:** if you don't have your phone or any backup codes, [recover access with your administrator](/en/ailita/recuperar/segundo-factor).

### How backup codes work

- Each code works once.
- They're shown only when you set up the app, on **Save your backup codes**.
- When you run out, go to **My account** → **Security** → **Authenticator app** and select **Generate new codes**. You need to be able to sign in to do this.

### Your organisation requires a second factor.

**Why:** your organisation requires an authenticator app to sign in and you haven't set one up yet.

**What to do:** follow the steps on **Protect your account**: scan the QR code with Google Authenticator, 1Password, Authy or a similar app, or use **Can't scan? Enter this key:**. Type the code from the app, save your backup codes and select **I saved them**.

**Still stuck:** talk to your administrator, or [ask for help](/en/ayuda/soporte).

### I lost my phone and my backup codes

On the **Two-step verification** screen, select **Lost your phone and backup codes?**. An administrator of your organisation confirms your identity and sends you a link. The full steps are in [I lost my second factor](/en/ailita/recuperar/segundo-factor).
