# T-07: English version of every page and language switcher

- **Roadmap:** ../ROADMAP.md · **Phase:** 3 · **Repo:** nesolva/docs · **Base branch:** release/public-docs-p3 (PR targets it, not main) · **Branch:** docs/public-docs-en
- **Depends on:** phase 2 merged · **Model:** sonnet

## Goal
Every Spanish page has an English version, and the site shows a language switcher. A reader can follow every
guide in English with the same structure.

## Scope
- Files/areas: `en/**` (new), `docs.json` (add the `en` entry to `navigation.languages`, mirroring `es`),
  `snippets/` (English variant of the help snippet).
- Out of scope: changing the Spanish pages. If you find an error in one, note it under Result.

## Contract
- Same paths as `es/`, under `en/`. Same nav structure and order.
- UI labels and error messages: use the English text from SOURCE-FACTS.md, never your own translation. If a label
  has no English text there, keep the Spanish one in **bold** and list it under Result.
- Roadmap Decisions and Contracts apply (content rules, no numbers for limits).

## Acceptance criteria (executable)
- [ ] Every `es/` page has an `en/` page — `diff <(cd es && find . -name '*.mdx' | sort) <(cd en && find . -name '*.mdx' | sort)` prints nothing
- [ ] Every page in `docs.json` exists — `node scripts/check-nav.mjs`
- [ ] No broken links — `npx mint@latest broken-links`
- [ ] Content check passes — `bash scripts/check-public-content.sh`
- [ ] The switcher appears and both languages render locally — `npx mint@latest dev`, open `/es` and `/en`, and describe it under Result
