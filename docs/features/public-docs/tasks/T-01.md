# T-01: Remove the template, set up the skeleton, add the content check

- **Roadmap:** ../ROADMAP.md · **Phase:** 1 · **Repo:** nesolva/docs · **Base branch:** release/public-docs-p1 (PR targets it, not main) · **Branch:** docs/public-docs-skeleton
- **Depends on:** none · **Model:** sonnet

## Goal
docs.nesolva.com no longer shows anything from the Mintlify template. It has the final structure (tabs, groups and
pages, in Spanish) with a stub on every page. Every PR runs a check that blocks forbidden content and broken links.

## Scope
- **Delete:**
  - `essentials/`, `ai-tools/`, `api-reference/`, `development.mdx`, `quickstart.mdx`,
    `snippets/snippet-intro.mdx`, the root `index.mdx`;
  - the template images in `images/` that nothing references any more. Keep the logos and favicons that
    `docs.json` uses.
- **Rewrite:**
  - `README.md`: what the site is, how to preview it and how to run the checks.
  - `CONTRIBUTING.md`: how to propose a change, and that every page passes `scripts/check-public-content.sh`.
  - `AGENTS.md`: remove the "First-time setup" block, fill in Terminology with the names from SOURCE-FACTS.md and
    keep Style.
- **`docs.json`:**
  - Use `navigation.languages` with a single entry, `es` (default), holding the tabs below.
  - Remove the `global.anchors` that point to mintlify.com.
  - Replace the navbar's "Dashboard" button. If there's no public product URL in SOURCE-FACTS.md, remove it and
    keep only Support.
  - Keep the footer socials, and check that each URL responds.
  - Set `name` to "Nesolva | Ayuda".
- **`.mintignore`:** make sure `docs/` and `scripts/` are excluded.
- **Create `snippets/necesitas-ayuda.mdx`:** "¿Necesitas ayuda?", with a link to `support+docs@nesolva.com` and to
  `/es/ayuda/soporte`.
- **Create `scripts/check-public-content.sh`:** it fails (exit 1) and prints file:line when any `.mdx` under `es/`,
  `en/` or `snippets/` matches, case-insensitively, any of these:
  - `fingerprint`, `huella digital`, `vpn`, `incognito`, `incógnito`;
  - `\bbot\b`, `heur[ií]stic`, `umbral`, `threshold`, `puntaje de riesgo`, `risk score`;
  - `src/`, `/api/`, `localStorage`, `sessionStorage`, `cookie`, `httponly`, `jwt`, `access token`,
    `refresh token`;
  - `[0-9]+ *(intentos|attempts|minutos|minutes|horas|hours|días|days|segundos|seconds)`;
  - any line with `TODO` or `PENDIENTE` outside a stub (the stub marker is `{/* stub */}`).

  Stubs are allowed in phase 1. Add a `--no-stubs` flag that also fails on `{/* stub */}`.
- **Create `scripts/check-nav.mjs`:** fails if a page listed in `docs.json` has no file, or an `.mdx` under `es/` or
  `en/` isn't listed.
- **Create `.github/workflows/docs-check.yml`:** on every PR and push to main, run `check-public-content.sh`,
  `node scripts/check-nav.mjs` and `npx mint@latest broken-links`, on Node 20.
- **Create a stub for each page below:** frontmatter (`title`, `description`, `icon`), one sentence on what the page
  will cover, `{/* stub */}`, and the help snippet.

  **Tab "Inicio"**
  - `es/index`: what Nesolva is, with cards to Ailita, Alfred and Ayuda.

  **Tab "Ailita"**
  - Primeros pasos: `es/ailita/introduccion`, `es/ailita/crear-cuenta`, `es/ailita/iniciar-sesion`.
  - Tu cuenta: `es/ailita/cuenta/datos-personales`, `es/ailita/cuenta/seguridad`, `es/ailita/cuenta/aplicaciones`,
    `es/ailita/cuenta/dispositivos-y-sesiones`, `es/ailita/cuenta/actividad`.
  - Recuperar el acceso: `es/ailita/recuperar/contrasena`, `es/ailita/recuperar/segundo-factor`.
  - Solución de problemas: `es/ailita/problemas/iniciar-sesion`, `es/ailita/problemas/codigos-y-segundo-factor`,
    `es/ailita/problemas/cuenta-e-invitaciones`.
  - Para administradores:
    - `es/ailita/admin/introduccion`, `es/ailita/admin/usuarios-e-invitaciones`, `es/ailita/admin/roles`;
    - `es/ailita/admin/acceso-y-seguridad`, `es/ailita/admin/dominios-y-sso`,
      `es/ailita/admin/casilla-de-facturacion`;
    - `es/ailita/admin/recuperacion-de-acceso`, `es/ailita/admin/problemas`.

  **Tab "Alfred"**
  - `es/alfred/introduccion`, `es/alfred/ingresar`, `es/alfred/panel-y-tareas`, `es/alfred/subir-factura`;
  - `es/alfred/revisar-tarea`, `es/alfred/facturas`, `es/alfred/ordenes-de-compra`, `es/alfred/problemas`.

  **Tab "Ayuda"**
  - `es/ayuda/soporte`, `es/ayuda/preguntas-frecuentes`, `es/ayuda/novedades`, `es/ayuda/datos-y-privacidad`.
- **Redirects:** if the old pages appear in search results, redirect `/ailita/:slug*` to `/es/ailita/introduccion`.
  The other old paths go to `/es`.
- **Out of scope:** the actual content of the pages (phase 2) and the English version (phase 3).

## Acceptance criteria (executable)
- [ ] No template files left — `ls essentials ai-tools api-reference development.mdx quickstart.mdx 2>&1 | grep -c "No such file"` prints 5
- [ ] No links to mintlify.com in the config — `! grep -n "mintlify.com" docs.json` (except `$schema`: `grep -n mintlify.com docs.json | grep -v '\$schema'` prints nothing)
- [ ] The nav and files match — `node scripts/check-nav.mjs`
- [ ] The content check passes on the stubs and fails on a test file containing "fingerprint" — `bash scripts/check-public-content.sh && printf 'fingerprint\n' > es/tmp-check.mdx && ! bash scripts/check-public-content.sh; rm -f es/tmp-check.mdx`
- [ ] No broken links — `npx mint@latest broken-links`
- [ ] The site renders — `npx mint@latest dev`: `/es`, one page per tab, and `/ailita/fingerprinting` redirects (describe it under Result)
- [ ] The workflow runs on the PR and goes green — `gh pr checks <pr>`
- [ ] No file under `es/`, `snippets/` or `docs.json` mentions anything the content rules in your brief forbid (re-read them before opening the PR)
