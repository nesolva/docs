# T-04: Ailita, recover access and troubleshooting (end users)

- **Roadmap:** ../ROADMAP.md · **Phase:** 2 · **Repo:** nesolva/docs · **Base branch:** release/public-docs-p2 (PR targets it, not main) · **Branch:** docs/ailita-problemas
- **Depends on:** T-01 merged · **Model:** sonnet

## Goal
A user who can't get in solves it alone or knows exactly whom to ask. That covers:
- a forgotten password;
- a lost phone or lost backup codes;
- a code that doesn't arrive or doesn't work;
- a session that closes;
- an expired invitation;
- the "No podemos continuar" screen.

## Scope
- Files/areas: `es/ailita/recuperar/*.mdx`, `es/ailita/problemas/*.mdx`, five stubs from T-01.
- Source:
  - SOURCE-FACTS.md, section A, "Forgot password", "Lost second factor" and the Ailita ID messages table;
  - the "No podemos continuar" errors.
- Out of scope: `docs.json` and the other pages.

## Contract
- Roadmap Decisions and Contracts, and the troubleshooting shape.
- Distribute the messages:
  - `problemas/iniciar-sesion`: credentials, SSO, passkeys, "No podemos continuar", disabled account or suspended
    organization, blocked sign-in, network.
  - `problemas/codigos-y-segundo-factor`: email codes, authenticator, backup codes, resend.
  - `problemas/cuenta-e-invitaciones`: sign-up, invitations, password requirements, email change, "Confirmá que sos
    vos".
- Common cases to add even though they aren't a message:
  - The code doesn't arrive: check spam and the right address, use **Reenviar código**, wait. No times.
  - The authenticator code fails: the phone's time is set automatically, and the right account is selected in the
    app.
  - The session closes unexpectedly: the organization may have chosen a maximum session length or an idle timeout,
    or someone closed your sessions after a password or security change.
- For "Bloqueamos el ingreso por seguridad", use only the text in SOURCE-FACTS.md. Don't explain why it happens.
- `recuperar/segundo-factor`: the full flow with the administrator, and what the user should have at hand.
